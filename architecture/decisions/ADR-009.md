# ADR-009: Safety: trusted triggers, untrusted-text tagging, hard budgets, diff guard

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D9 Safety and failures

## Context

Anyone can open an issue, so issue text may contain prompt injection. Actions jobs have time limits; models can loop or stall; API spend must be capped.

Options considered:
1. Trust the model to ignore injected instructions
2. **Layered: only trusted users can trigger; issue text wrapped in <untrusted_issue> tags and passed via env, never interpolated into `run:`; no tokens or network tools in agents; diff_guard rejects changes to .github/, autose/, CODEOWNERS; turn limit per call, token cap per run, timeout-minutes per job, retry caps; failures stop the run with the reason written in the artifact**

## Decision

See options in bold. A test issue with an injection attempt is run and recorded.
