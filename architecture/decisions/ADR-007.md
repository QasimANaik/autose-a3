# ADR-007: Stage checks are deterministic code; the orchestrator makes the pass/fail decision

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D7 Checks

## Context

Each stage may only hand over after its check passes. LLM self-assessment ("I think the tests pass") is unreliable.

Options considered:
1. LLM judge decides every check
2. **Code checks: spec_lint (AC ids + Given/When/Then), design_refs (named files/functions exist via AST), build (uv sync, import, ruff, mypy), diff_guard, pytest exit code, CI conclusion; reviewer verdict is the only LLM decision**
3. Tests only

## Decision

The orchestrator runs each check as code and decides pass/fail. Agents never report their own pass/fail.

## Consequences

- Checks are reproducible and cheap.
- Structural checks can pass a weak spec (an AC can be formally testable but wrong).
- Signal to revisit: a stage passes its check but the next stage fails because of it.
