# ADR-008: Reviewer independence through separate job, model, prompt, permissions and evidence rule

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D8 Reviewer independence

## Context

The reviewer must not simply agree with the implementer. It may see only the issue, the diff and the repo at the PR head, and may run code but not push.

Options considered:
1. Same agent reviews its own work
2. Separate prompt only
3. **Separate job (contents:read), different model, adversarial prompt, no builder artifacts, every finding needs evidence (file:line or command output), verdict posted by a no-LLM publish job; calibrated on 5 seeded PRs incl. one clean PR**

## Decision

See decision options in bold. The reviewer must list what it checked before it may approve.

## Consequences

- Independence is enforced by GitHub permissions, not just by instructions.
- Evidence rule reduces vague objections.
