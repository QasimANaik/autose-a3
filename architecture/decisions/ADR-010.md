# ADR-010: Trigger on label or /autose comment from trusted users; one queued run per issue

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D10 Triggers

## Context

Maintainers start the workflow by label or comment. issue_comment fires for every comment including the bot's own. Two runs on the same issue could push to the same branch.

Options considered:
1. Any comment/label from anyone
2. **`issues.labeled` with label `autose`, or a comment starting with `/autose` (`/autose review` on a PR) from OWNER/MEMBER/COLLABORATOR; bot comments ignored; `concurrency: autose-<issue>` with cancel-in-progress false**
3. workflow_dispatch only

## Decision

See options in bold. `workflow_dispatch` is kept for experiments and re-runs.

## Consequences

- Second trigger on the same issue waits instead of racing.
- Only people with triage/write access can start a run (label requires triage).
- Queued runs may redo work if the first one already succeeded.
- Signal to revisit: duplicate PRs for one issue.
