# ADR-003: Hand-offs are full artifact files; the reviewer gets no builder artifacts

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D3 Hand-offs

## Context

Each fresh agent call only knows what it is given. Passing everything (transcripts) wastes tokens and leaks
reasoning; passing too little loses requirements. The reviewer must see only issue, diff and repository.

Options considered:
1. Full transcripts of earlier stages
2. LLM-written summaries of earlier stages
3. **Full artifact files (spec.md, design.md, test_report.md) chosen per stage + repository access; ARCHITECTURE.md for design**
4. Repository access only

## Decision

Each stage receives specific artifact files (table in PLAN.md §4.5) plus read access to the repository. Transcripts are
saved for humans but never passed to another agent. The reviewer receives only the issue text, the PR diff and the PR-head checkout.

- Test stage gets the spec ACs but not the design rationale, so tests follow requirements.
