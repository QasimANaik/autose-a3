# ADR-004: State lives in workflow artifacts plus a marker comment; nothing builder-internal on the PR branch

**Date:** 2026-11-23
**Status:** Proposed
**Decision area:** D4 State

## Context

State must flow between stages, between jobs (build → review → rework) and between runs (restart via `/autose`).
The reviewer checks out the PR branch, so anything stored on that branch is visible to it.

Options considered:
1. Artifact files committed to the PR branch (.autose/)
2. PR comments only
3. **Workflow artifacts (out/ uploaded per job) + a machine-readable `<!-- autose-state -->` comment on the issue for re-runs; branch holds only code + tests**
4. Actions cache

## Decision

We will keep artifacts as uploaded workflow artifacts (and copy them into the submission repo for grading), keep the
branch clean of builder reasoning, and record run state in a marker comment so a re-run resumes from the last passed stage.

## Consequences

- Reviewer independence is preserved because builder artifacts are not on the branch.
- Artifacts expire (90 days), so they must be downloaded for the submission.
- Restart logic must download the previous run's artifacts.
- Signal to revisit: resumed runs behave differently from fresh runs.
