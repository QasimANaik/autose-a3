Open `.drawio` files in VS Code (Draw.io Integration extension) or at app.diagrams.net. The `.drawio` files are generated by
`src/gen_architecture.py` (component view) and `src/gen_views.py` (stage map, sequence view):
`python3 architecture/views/src/gen_architecture.py && python3 architecture/views/src/gen_views.py`.

- `reference/specbridge-architecture.drawio`: the maintainers' existing LangGraph agent (SpecBridge) whose structure
  the workflow follows (ADR-011, ADR-012).
- `archive/`: earlier versions of the views, kept to show how the design changed (v1 = hand-written state machine, before
  the LangGraph rebuild; superseded ADR-001/002/004).
